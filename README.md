# Kanban Board (Django + JS)
Веб-приложение для управления задачами по методологии Kanban, разработанное на Django и JavaScript.

## Возможности
- Регистрация и авторизация пользователей
- CRUD для досок
- CRUD для колонок
- CRUD для задач
- Drag-and-drop для колонок
- Динамическое обновление интерфейса (AJAX) (В разработке)
- Добавление нескольких пользователей на выполнение задачи (В разработке)
- Хранение данных в PostgreSQL
- Запуск приложения через Docker Compose

## Запуск
Запуск предусмотрен с помощью docker compose.
Для запуска необходимо в директории приложения выполнить команду `docker compose up -d`.
После можно открыть приложение по адресу 127.0.0.1:8000
