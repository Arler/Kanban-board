## Kanban Board (Django + JS)
Рабочее веб-приложение для управления задачами

### Функционал
- Drag-and-drop для колонок
- Модальные формы
- Авторизация пользователей

### Запуск
- Запуск предусмотрен с помощью docker compose.
- Для запуска необходимо в директории приложения выполнить команду `docker compose up -d`.
- После можно открыть приложение по адресу 127.0.0.1:8000

### Особенности проекта
- Динамическая загрузка элементов страницы для увеличение производительности и уменьшения веса страницы
    > Реализовано конкретно в файле main_page.js и соответствующем API в api/views.py
